# LK 테크 채용·근태·인력 관리

공개 홈페이지: https://johnpark236-tech.github.io/LK_tech/

저장소: 비공개 Google Sheets. 신청자 개인정보·위치·상담 내용·관리자 비밀키는 이 공개 저장소에 저장하지 않습니다.

## 최초 연결 (소유자 1회)

1. [관리 시트](https://docs.google.com/spreadsheets/d/14nus_yGwAIZu5J29FULfIFVBRYFBXkXpgAvXuQAGcqI/edit)를 엽니다. 공유 설정은 제한됨으로 유지합니다.
2. 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
3. `apps-script/Code.gs` 파일 전체를 편집기에 넣고 저장합니다.
4. 함수 `install`을 한 번 실행하고 본인 Google 계정에서 권한을 검토·승인합니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 설정합니다. 시트를 공개하는 것이 아니라, 검증된 API만 웹 앱으로 제공합니다.
6. 반환된 `/exec` 웹 앱 URL을 `config.js`의 `appsScriptUrl`에 넣습니다. 이 주소는 공개 연결 주소이며 관리자 비밀키가 아닙니다.
7. 관리 시트를 새로고침하고 **LK 테크 → 관리자 접속키 보기**에서 확인한 키로 홈페이지의 **운영자 로그인**을 이용합니다. 키는 채팅이나 GitHub 파일에 게시하지 마세요.

## 기능

- 작업자·관리자 신청: 이름·전화번호·저장 동의 필수 (보유기간·동의 거부 안내 포함)
- 관리자 신청 승인·해제: 운영자만 가능
- 상담: 같은 기기·브라우저와 승인된 관리자만 확인
- 근태: 등록 근무지 반경 안에서 현재 위치·서버 시간을 저장하고 승인 대기로 접수
- 월별 조회: 출근·퇴근 모두 승인된 날짜만 인정 일수로 집계
- 출퇴근은 버튼을 누를 때만 위치를 읽습니다. GPS 오차와 위치 변조 가능성이 있어 현장 확인이 필요합니다.

## 서버 업데이트 (휴대폰 한 번 누르기)

운영자 로그인 → **관리자 승인** 탭 맨 위 **🔄 서버 업데이트** → 버튼. 서버가 GitHub `main`의 `apps-script/Code.gs`·`appsscript.json`을 받아
코드를 검증한 뒤, 홈페이지가 쓰는 같은 배포 주소에 새 버전으로 배포합니다. 코드 변경 시 `CODE_VERSION`을 올리세요.

**최초 1회 설정 (PC 권장)**
1. https://script.google.com/home/usersettings → **Google Apps Script API: 사용**
2. Apps Script 편집기 → 프로젝트 설정(톱니) → **'편집기에서 appsscript.json 매니페스트 파일 표시'** 체크
3. 편집기의 `appsscript.json`을 저장소의 `apps-script/appsscript.json` 내용으로, `Code.gs`를 최신 내용으로 교체 → 저장
4. `install` 실행 → 새 권한(드라이브, Apps Script 프로젝트·배포 관리) 허용
5. 배포 → 배포 관리 → 연필 → 새 버전 → 배포

이후 매니페스트의 권한이 늘어나는 업데이트가 있으면, 업데이트 직후 운영자가 웹 앱 주소(/exec)를 한 번 열어 권한을 다시 허용합니다.

## 인력 관리 (관리자 · 운영자)

홈페이지 상단 **인력 관리** 탭 (승인된 관리자에게만 보임)

- **신고 마감 알림**: 매월 10일 원천세, 15일 근로내용확인신고, 말일 일용근로소득 지급명세서 D-day 표시
- **지원자 → 작업자 등록**: 숙련 단계(입문 14만 · 숙련 15만 · 전문 17만 기본값)를 골라 채용 등록. 일급은 그날 맡은 공정이 아니라 본인 단계 기준이며 작업자별 수정 가능. 등록·수정은 승인된 관리자 누구나 가능하며, 시트 작업자 탭에 채용관리자·최종수정관리자·최종수정일 기록
- **월간 정산**: 출근·퇴근이 모두 승인된 날을 근무일로 집계 → 지급총액, 소득세((일급−15만)×6%×45%), 지방소득세, 고용보험 0.9%, 실지급액 계산 (월 1회 지급 기준, 소득세 1,000원 미만 소액부징수)
- **월 8일 알림**: 월 8일 이상 또는 60시간 이상이면 국민연금·건강보험 취득신고 대상 표시, 6~7일이면 사전 경고
- **CSV 내보내기**: 근로내용확인신고 보조자료(일자별 근로일 표시 + 국세청 항목), 급여대장. 엑셀에서 바로 열림
- 주민등록번호는 저장하지 않습니다. 신고 화면에서 직접 입력하세요. CSV는 신고서 작성 보조자료이며 공단 일괄신고 양식에 맞춰 옮겨 적습니다.
- 기존 시트에 **작업자** 탭이 없으면 Apps Script에서 `install`을 한 번 더 실행하세요 (없는 시트만 생성).
- `config.js`의 `business` 항목에 대표자·사업자등록번호·주소·전화번호를 넣으면 홈페이지 하단에 표시됩니다.
- 관리자 신청 메뉴는 공개 화면에서 숨겼습니다. 관리자 후보에게는 `…/LK_tech/#staff` 주소를 안내하세요.

## 전자 근로계약서 (현장 대면 서명)

- 인력 관리 › 작업자 명부의 **계약서** 버튼 → 관리자 휴대폰에서 작성 → 사업주 서명 → 휴대폰을 근로자에게 건네 확인·서명 → **서명 완료·저장**
- 브라우저에서 PDF(A4)를 만들고 SHA-256 고유값을 계산해 서버로 전송 → 서버가 고유값·PDF 형식을 재확인 후 관리 시트가 있는 폴더의 **근로계약서 보관** 폴더에 저장, **근로계약서** 시트에 기록
- 완료 화면: 카카오톡 등으로 PDF 공유(휴대폰 공유 기능), PDF 다운로드, 근로자용 다운로드 링크(`#contract=코드`) 복사, 이메일
- 근로자는 받은 링크로 홈페이지에서 언제든 PDF를 다시 받을 수 있음 (코드는 시트에 해시로만 저장)
- 사업주 정보는 인력 관리 › **근로계약서 양식(사업주 정보) 미리 작성**에서 관리자별로 저장(최대 20개). 계약서 작성 시 양식을 고르면 사업체명·대표자·사업자등록번호·대표 전화·주소·기본 근무장소가 채워지고, 그 자리에서 수정하거나 새 양식으로 저장 가능.
- 주민등록번호는 계약서에 넣지 않습니다. 근로계약서는 3년 보관(근로기준법 제42조).
- Apps Script가 드라이브에 파일을 저장하므로, 새 Code.gs 반영 후 `install`을 한 번 실행해 드라이브 권한을 허용하세요.

## 운영 전 확인

- 아직 `config.js`가 비어 있으면 홈페이지는 연결 준비 중으로 표시하며 신청을 접수하지 않습니다.
- 실제 근무지 주소·좌표·반경을 등록한 다음 출퇴근을 사용합니다.
- 쿠키/브라우저 저장 데이터를 지우거나 기기를 바꾸면 기존 기기 기록 접근 및 관리자 승인이 이어지지 않습니다.
- 카카오톡 알림은 별도 ChatGPT 예약 작업에서 `알림대기` 시트의 미발송 건을 확인해 보내는 방식이며 즉시 발송을 보장하지 않습니다.
- Google Apps Script 실행·저장 할당량을 초과하면 접수가 일시 실패할 수 있습니다.
- 기존 Sites에 저장된 과거 기록은 자동 이전되지 않습니다.

관리자 = 승인받은 구글 계정으로 로그인한 사람. 지원자는 로그인 없이 신청합니다.

2로그인

  1. 홈페이지 맨 아래 Google로 로그인을 누르고 본인 구글 계정을 선택합니다.
  2. “○○@gmail.com 로그인됨”이 보이면 위쪽에 상담함 인력 관리 📖 매뉴얼이 나타납니다.
  3. 다 쓰면 맨 아래 로그아웃.

“액세스 차단됨”이 뜨면 그 계정이 Google Cloud의 테스트 사용자에 없는 것입니다. 담당 책임자에게 본인 구글 이메일을 알려 주고 등록을 요청하세요. (자주 묻는 문제)

↑ 맨 위로

3관리자 등록 받기

  1. 안내받은 주소(홈페이지 주소 끝에 #staff)로 들어갑니다.
  2. 맨 아래 Google로 로그인 → 관리자 신청에 이름·전화번호를 넣고 신청합니다.
  3. 승인되면 다시 로그인했을 때 상담함 인력 관리가 보입니다. 휴대폰·PC 어디서든 같은 구글 계정으로 로그인하면 됩니다.

관리자로 등록된 사람은 작업자 채용 목록에 나오지 않습니다.

↑ 맨 위로

4지원자·상담 확인

  1. 상담함을 누르면 지원자 목록이 나옵니다. 🟠 확인 필요 / 🟢 안내 완료
  2. 항목을 누르면 지원 내용(이름·전화번호)과 상담 대화가 열리고, 아래 칸에 답변을 보낼 수 있습니다.
  3. 전화로 연락해 근무 여부를 정한 뒤 작업자 등록으로 넘어갑니다.
↑ 맨 위로

5작업자 등록 (채용)

  1. 인력 관리 → 지원자 → 작업자 등록 목록에서 해당 지원자를 찾습니다.
  2. 숙련 단계 선택: 입문(14) · 숙련(15) · 전문(17) — 일급이 자동으로 들어갑니다.
  3. 일급(만원)을 필요하면 수정합니다. 16.5 = 165,000원 (칸 아래에 원 단위 표시)
  4. 채용 등록 → 확인창에서 금액 확인 → 확인

일급은 그날 맡은 공정과 관계없이 본인 숙련 단계 기준입니다. 단계가 오르면 작업자 명부의 수정에서 단계·일급을 바꾸고 변경 계약서를 다시 서명합니다.

채용 등록과 일급 수정은 승인된 관리자 누구나 할 수 있습니다. 누가 채용했는지는 작업자 명부의 채용 칸에 표시되고, 이름에 손가락·마우스를 올리면 마지막으로 고친 사람도 보입니다.

↑ 맨 위로

6근로계약서 양식(사업주 정보) 미리 작성

처음 한 번만 해 두면 계약서를 쓸 때 고르기만 하면 됩니다. 관리자마다 따로 저장(최대 20개)됩니다.

  1. 인력 관리 아래쪽 근로계약서 → 📝 근로계약서 양식(사업주 정보) 미리 작성
  2. 양식 이름(예: LK 테크 · 직산), 사업체명, 대표자, 사업자등록번호, 대표 전화, 기본 근무장소, 사업장 주소 입력
  3. 양식 저장 — 목록에서 수정 / 삭제 가능

현장이나 업체가 여러 곳이면 양식을 여러 개 만들어 두세요.

↑ 맨 위로

7근로계약서 작성·서명 (현장 대면)

  1. 인력 관리 → 작업자 명부에서 작업자 줄 오른쪽 계약서
  2. 사업주 정보: 저장된 양식 선택 → 자동 입력 (그 자리에서 수정 가능, 이 사업주 정보를 양식으로 저장)
  3. 근로자·근로조건: 생년월일, 계약 기간(1일 계약이면 종료일 비움), 근무장소, 시간, 일급(만원) 확인
  4. 계약서 미리보기 · 서명하기 → 내용 확인 → 사업주 서명(손가락) → 근로자 서명으로
  5. 📱 휴대폰을 근로자에게 건넵니다. 근로자가 내용을 보고 “확인했으며 사본을 받는 데 동의” 체크 → 서명
  6. 서명 완료 · 저장 → PDF가 만들어져 회사 드라이브 근로계약서 보관 폴더에 저장

주민등록번호는 계약서에 넣지 않습니다(4대보험 신고 때 따로 받음). 근로계약서는 3년 보관해야 합니다.

PDF 하단에 계약번호·서명 시각·대면 확인한 관리자 계정이 찍히고, 파일 고유값(SHA-256)이 함께 보관되어 나중에 위·변조 여부를 확인할 수 있습니다.

↑ 맨 위로

8계약서 사본 전달

서명 완료 화면에서 근로자에게 바로 보내세요. (교부하지 않으면 근로기준법 위반)

버튼하는 일
카카오톡 등으로 공유휴대폰 공유창이 열려 PDF를 카톡·문자로 바로 전송
근로자용 다운로드 링크 복사근로자가 이 링크로 홈페이지에서 언제든 PDF를 다시 받음
PDF 다운로드관리자 휴대폰에 저장
이메일로 보내기링크가 담긴 메일 작성 (PDF는 직접 첨부)

나중에 다시 필요하면 인력 관리 → 근로계약서 목록 → PDF 받기.

↑ 맨 위로

9출퇴근 기록·승인

  1. 작업자: 현장에서 근태 기록 → 근무지 선택 → 동의 체크 → 출근 기록 / 퇴근 기록
  2. 관리자: 같은 화면 아래 근태 승인에서 기록별 승인 / 반려(사유 입력)

근무지 선택 목록이 비어 있으면 담당 책임자에게 현장 주소 등록을 요청하세요. 출근·퇴근이 둘 다 승인된 날만 근무일로 계산됩니다. 본인 기록은 다른 관리자가 승인해야 합니다.

↑ 맨 위로

10월간 정산·CSV

  1. 인력 관리 → 월간 정산에서 월 선택 → 정산 새로고침
  2. 사람별 근무일·시간·지급총액·소득세·지방세·고용보험(0.9%)·실지급액 확인
  3. 근로내용확인신고 자료 (CSV) / 급여대장 (CSV) 다운로드 (엑셀로 열림)
표시의미
🔴 국민연금·건강보험 취득신고 대상그 달 8일 이상 또는 60시간 이상 근무 → 다음 달 15일까지 취득신고 검토
🟡 곧 8일6~7일 근무 — 일정 조정 참고
일급 미등록출퇴근은 있으나 작업자 등록이 안 됨 → 작업자 등록

소득세 = (일급 − 15만원) × 6% × 45%, 월 1회 지급 기준, 1,000원 미만은 0원(소액부징수). 신고 전 세무대리인 금액과 비교해 보세요.

↑ 맨 위로

12자주 묻는 문제

“계약서” 버튼이 안 보여요

아직 채용 등록이 안 된 사람입니다. 또는 로그인한 계정이 관리자 승인을 받지 않았습니다.

구글 로그인 시 “액세스 차단됨”

아직 로그인이 허용되지 않은 계정입니다. 담당 책임자에게 본인 구글 이메일을 알려 주세요.

“아직 관리자 권한이 없습니다”

로그인은 됐지만 승인 전입니다. 승인이 끝나면 다시 로그인해 보세요.

“구글 로그인이 만료되었습니다”

로그인은 약 1시간 유지됩니다. 맨 아래 Google로 로그인을 다시 누르세요.

계약서 저장 중 오류

잠시 후 다시 시도하고, 계속되면 화면에 나온 문구를 담당 책임자에게 알려 주세요.

근로자가 계약서를 다시 달라고 해요

처음 보낸 다운로드 링크로 언제든 받을 수 있습니다. 링크를 잃어버렸으면 근로계약서 목록에서 PDF 받기 후 다시 보내 주세요.
